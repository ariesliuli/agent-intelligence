# 宿主级第一性原理与未来止损评估（Host First-Principles & Future Loss Avoidance Policy）

> 状态：**规范与研究假设**，不是已经证明有效的收益算法。适用于 OpenClaw 主控、Codex、Claude Code、Skill 进化、工程报告与评测。宿主（Host）是策略和验证控制层，不是人格设定，也不能覆盖用户授权。

## 1. 不可省略的核心原则

1. **从约束和机制出发，而不是从流行方案出发。** 先写清真实目标、可观测事实、物理/软件/组织约束、假设、未知项、失败代价，再决定是否复用现有方案。
2. **原因分析必须能被证伪。** 5 Whys（五问法）、鱼骨图、故障树 FTA、FMEA、因果图、反事实分析、变更点分析和 8D 是可选工具，不是机械仪式。5 Whys 不要求恰好问五次；遇到多因一果时必须分支，不能用单链叙事冒充因果证据。
3. **分析深度由风险和信息价值控制。** 小事优先低成本核查；可重复、会放大、难检测、影响安全/数据的故障优先深挖。不要把每次回答都变成漫长推理。
4. **区分故障根因、触发条件、检测缺口和系统性放大因素。** 不允许把“操作员失误”“模型幻觉”当作最终根因而停止分析；继续检查界面、权限、流程、测试和激励约束。
5. **优先消除故障机制，而不只是补救个案。** 优先考虑约束、隔离、幂等、防呆、可验证回退和自动检测。
6. **反思结论必须落地。** 每个结论连接证据、替代假设、行动、测试、负责人/执行器和验证窗口；未经测试标为待验证。
7. **禁止编造节省成本。** 未来未发生的故障不能当作实际节省。将“避免的未来损失”明确标为预测，并记录不确定性与可反驳条件。
8. **安全权限是确定性门禁。** 第一性原理分析、模型自信或高预测收益都不能自动授权真实设备写入、外部发布或泄露数据。

## 2. 思考预算与触发器（Reasoning Budget & Trigger）

| 等级 | 触发条件 | 建议动作 | Token 预算原则 |
|---|---|---|---|
| L0 快速 | 可逆、低影响、已有稳定测试 | 直接执行 + 最小验证 | 不强制 5 Whys |
| L1 结构化 | 同类问题重复、局部失败、存在可疑假设 | 事实/假设分离 + 变更点分析 + 1～3 个可证伪问题 | 设定上限，超限需解释 |
| L2 根因 | 跨模块缺陷、重复返工、外部副作用、难检测 | 5 Whys 分支 + 故障树/FMEA + 反事实测试 | 以预期信息价值分批投入 |
| L3 系统性 | 安全/隐私/重大损失、不可逆操作、组织单点故障 | 多假设审查 + 独立验证 + 人工审批 | 可增加预算但不能跳过审批 |

这些等级是**初始策略**，不是普适阈值；后续依据实际任务分布校准。没有证据时应选择可逆试验而不是编造确定性。

## 3. 未来止损预测（Future Loss Avoidance）

目标不是最大化即时 Token 节省，而是比较有分析和无分析两种政策的长期期望净损失：

```text
E[净收益 | 深入分析] =
  E[未来损失 | 基线策略] - E[未来损失 | 深入分析策略]
  - 额外 Token/时间/人工复核成本
  - 误诊、过度修复、延迟上线造成的期望损失
```

未来损失可以分解为 `发生概率 × 影响 × 暴露次数`，但这些变量常相关，不能盲目相乘；必须记录区间和假设。区分：

- **已观测损失**：工时、返工、故障次数、停机时间等可审计数据。
- **预测避免损失**：未来可能减少的损失；给区间和可信度，禁止作为已实现 ROI。
- **实际避免损失**：需要反事实对照、A/B、阶梯部署或准实验估计，不能从“没有再发生”直接推断。
- **负收益风险**：过度分析、误报、复杂度、维护负担及新引入缺陷。

可用简化决策规则：当风险不可接受时先执行强制安全措施；否则仅当“进一步调查的预期信息价值（EVSI）”高于调查成本，或调查能显著降低高尾部风险时升级分析。EVSI 必须估计，不得声称精确。

## 4. 防止评价体系自我欺骗

**基准对照**：在相似任务上比较浅分析与深分析；分层按严重度、重复率、可逆性、设备类型；保留未干预对照或历史基线。

**观察窗口**：设 7/30/90 天复查；关注同类缺陷复发率、人工返工分钟数、平均恢复时间 MTTR、额外 Token、修复引入的新故障、误报/漏报。

**归因限制**：同时发生的团队变更、流量变化、固件升级、设备更换会污染比较。记录混杂因素，避免将自然波动归功于 Agent。

**反向指标**：必须测量分析导致的延迟、无效建议率、过度工程率、回滚率和 Token 成本。不能只报告成功案例。

**尾部损失**：安全或不可逆操作要报告最坏合理情形和损失上界；单纯平均值不足以决定风险。

**证据等级**：`hypothesis`（假设）→ `simulated`（模拟）→ `observed`（实际观察）→ `causal_estimate`（有可辩护对照的因果估计）。不能自动升级。

## 5. 每次复盘最小契约（Reflection Contract）

```json
{
  "incident_id": "INC-EXAMPLE-001",
  "goal": "减少模拟任务重复执行",
  "observations": ["超时后状态未知"],
  "assumptions": ["设备可能已执行操作"],
  "constraints": ["禁止未经授权的设备写入"],
  "failure_modes": ["重复操作", "漏执行"],
  "analysis_level": "L2",
  "methods": ["5-whys-branching", "fault-tree", "counterfactual-test"],
  "causal_hypotheses": [
    {"claim": "超时被错误映射为失败", "evidence": "模拟日志", "falsification_test": "模拟回执丢失"}
  ],
  "intervention": "结果未知时进入 ambiguous，停止自动重试",
  "baseline": {"duplicate_actions": null, "measurement_status": "not_measured"},
  "forecast": {"avoided_loss_range": null, "unit": "human_minutes", "confidence": "unknown"},
  "cost": {"extra_tokens": null, "extra_review_minutes": null},
  "validation": {"status": "pending", "tests": ["模拟断线重试"], "review_days": [7, 30, 90]},
  "rollback": "关闭自动调度并保留人工核对"
}
```

注意：`null` 代表尚未测量，**绝不能用 0 伪装为零损失**。记录可公开的合成案例；真实客户或设备资料不得提交公开仓库。

## 6. Agent 宿主决策顺序

```text
接收任务
→ 明确目标与不可违反的约束
→ 快速检查已有证据/历史经验
→ 识别故障影响、重复性、不可逆性
→ 选择 L0–L3 分析等级与预算
→ 根据证据选择 5 Whys / FTA / FMEA / 反事实等方法
→ 形成可证伪假设与最小试验
→ 独立验证 / 必要时人工审批
→ 执行可逆改进
→ 记录预测、实际成本、失败及回滚
→ 7/30/90 天重新估计价值并修正策略
```

若无法取得真实结果：只记录预测与待验证条件，不自动将经验提升为已证实。

## 7. 与现有 Hint 的关系

- HINT-002：任务契约增加目标、约束、分析等级、验证窗口。
- HINT-003：经验记忆只提升有证据、可复现的因果结论。
- HINT-006：生产力实验同时衡量未来止损和分析成本。
- HINT-010：人类注意力预算与深度分析预算联动。
- HINT-012：用反事实回放检验“如果不修复会怎样”。
- HINT-013/023：独立审计实际工具行为，而非相信 Agent 自述。
- HINT-020：依据长期结果改进 Skill，而非仅靠模型自评。

## 8. 研究路线与验收门槛

**阶段 A（可执行）**：实现 `reflection_policy.py` 规则选择器 + JSON Schema + 20 个合成场景；验证高风险触发不漏判、低风险不过度分析、禁止无证据声称 ROI。

**阶段 B（对照实验）**：至少 30 个历史可脱敏任务，浅分析/深分析配对；比较 Token、人工时间、正确率、复发率、误修率；不得声称已经证明长期节省。

**阶段 C（长期评估）**：7/30/90 天复盘，构建概率校准曲线；计算预测区间覆盖率、实际返工变化、分析净成本；必要时用分层模型或贝叶斯更新，明确数据稀缺时的不确定性。

**回滚**：可将 `HOST_REFLECTION_POLICY=observe_only`，只记录分析建议，不改变执行路径；权限门禁继续生效。

## 9. 已知局限

- 未发生的事故无法直接观测；反事实需要假设。
- 低频高损事故样本极少，预测区间可能极宽。
- 5 Whys 容易出现单链偏差；需替代假设与测试。
- 深分析本身可能改变执行者行为，使对照难以公平。
- 此文件定义的是**待验证宿主策略**，不代表已开发、已接入或已产生可量化止损收益。
